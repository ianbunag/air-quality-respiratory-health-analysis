# Air Quality Analysis for Health and Environmental Protection

An end-to-end data mining and machine learning pipeline analyzing the relationship between atmospheric pollutants (PM2.5, PM10, $O_3$, $NO_2$, $SO_2$, CO) and respiratory disease transmission patterns.

> **Context:** Graduate Research Project — **CMPE-255: Data Mining** (Spring 2026)  
> **Researchers:** [Hung Pham](https://github.com/hung-p), [Bhimsen Thapa Chhetri](https://github.com/bhimsenthapa1), & [John Ian Buñag](https://github.com/ianbunag)  
> **Technical Reports:** [Final Research Report (PDF)](./04-29-final-report.pdf) | [Progress Report (PDF)](./03-23-project-progress-report.pdf)
